### APP-02 실서버 확인 필요 항목
- #2 틀린 토큰으로 요청 → 설정 탭으로 이동하고 안내 토스트가 한 번만 뜨는지
- #4 실제 Matter·TCP_DIY 등록이 60초를 넘어도 끊기지 않는지(앱 150초)
- #5·#6 기기를 끈 상태에서 제어 → "제어 실패: 명령 실패!" 토스트, 상태가 OFFLINE으로 바뀌지 않는지
- #8 서버가 UNKNOWN을 줄 때 "알 수 없음"(주황) 표시
- #9·#10 상세 차트 시간이 현지 시간이고 왼쪽→오른쪽으로 흐르는지
- #11 서버를 끈 채 스위치·새로고침·삭제 → LOADING이 풀리는지
