### APP-02 실서버 확인 필요 항목
- #2 틀린 토큰으로 요청 → 설정 탭으로 이동하고 안내 토스트가 한 번만 뜨는지
- #4 실제 Matter·TCP_DIY 등록이 60초를 넘어도 끊기지 않는지(앱 150초)
- #5·#6 기기를 끈 상태에서 제어 → "제어 실패: 명령 실패!" 토스트, 상태가 OFFLINE으로 바뀌지 않는지
- #8 서버가 UNKNOWN을 줄 때 "알 수 없음"(주황) 표시
- #9·#10 상세 차트 시간이 현지 시간이고 왼쪽→오른쪽으로 흐르는지
- #11 서버를 끈 채 스위치·새로고침·삭제 → LOADING이 풀리는지

### APP-03 실서버 확인 필요 항목
- #12 없는 기기 ID로 E6 → 상태가 OFFLINE으로 바뀌지 않고 "전력 조회 실패: 등록되지 않은 기기입니다." 토스트
- #13 허용되지 않은 명령·삭제 실패·등록 실패 때 서버 문구가 토스트에 나오는지
- #14 상세·대시보드 차트가 구간 사용량(mWh)으로 그려지는지, 기록이 1개면 안내 문구가 나오는지
- #15 PC 드라이버 기기를 OFF → 약 50초 뒤 자동으로 상태를 다시 물어 OFF로 바뀌는지
