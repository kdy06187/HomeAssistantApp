1한눈에 보기

  • 배너: MainActivity 맨 위(모든 탭·상세·기기 추가 화면 위)에 연결 상태 배너를 둔다. 닿지 않음 → "서버에 연결할 수 없어요 · Wi-Fi와 서버 주소를 확인해 주세요 [다시 시도]", 토큰 오류 → "API 토큰이 맞지 않아요 [설정으로]".
  • F-01 해결: 토큰 오류 배너는 설정을 저장하거나 요청이 성공(2xx)할 때까지 계속 보인다. 첫 1번의 토스트·설정 탭 자동 이동은 그대로.
  • 설정 탭에서는 이미 고칠 곳에 있으므로 버튼 없이 "아래에서 새 토큰을 저장해 주세요"만.

3코드 해설

RetrofitClient.getConnectionState().observe(this,
        kind -> renderBanner(kind, bottomNav.getSelectedItemId() == R.id.nav_settings));
왜 MainActivity에서 배너는 탭과 상관없이 하나라서, 탭 Fragment마다 따로 그리면 탭을 바꿀 때 깜빡이거나 사라진다. 상태가 바뀔 때만 LiveData가 값을 내므로 요청이 많아도 배너가 깜빡이지 않는다.
예전(토스트만) 첫 401에 토스트 1번 뒤로는 아무 표시가 없어, 사용자는 왜 아무것도 안 되는지 몰랐다(F-01).

6응용 실습

새 브랜치에서: 닿지 않음 배너의 "다시 시도"를 누르는 동안 버튼을 잠그고 "확인 중…"으로 바꿔 보세요. 고칠 파일: MainActivity.renderBanner. 완료 기준: 상태가 바뀌면(배너가 다시 그려지면) 원래대로.
