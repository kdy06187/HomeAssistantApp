APP-07c-1 해설 — 상세를 Activity에서 Fragment로

ui-1 브랜치 · UI 1차 07c · D4(상세는 MainActivity 안 Fragment) · 2026-11-24

1한눈에 보기

  • 전: 타일을 누르면 DeviceDetailActivity가 따로 떴다. 이 Activity는 자기만의 ViewModel을 만들어 기기 목록이 비어 있었고, 상태 칸에는 실제와 상관없는 "정상 (Online)"이 적혀 있었다(UI-23).
  • 후: DeviceDetailFragment가 MainActivity의 같은 자리(fragmentContainer)에 뒤로 스택으로 쌓인다. 탭들과 같은 ViewModel을 써서 목록·제어·실패 Snackbar가 그대로 이어진다.
  • 내용은 카드 부품으로: 상태·제어 카드(StatusCard), 기기 정보 카드(InfoCard). 레이아웃도 카드마다 따로(detail_*_card.xml) 두고 <include>로 끼운다.
  • 상세가 열려 있는 동안 하단 탭은 숨긴다. 앱바 메뉴에 "타일 꾸미기" 자리만 있고(눌리지 않음), 동작은 07g에서 붙인다.

2흐름 그림 — 열기와 닫기

3코드 해설

① 뒤로 스택에 쌓기

fm.beginTransaction()
        .setReorderingAllowed(true)
        .replace(R.id.fragmentContainer, fragment)
        .addToBackStack(null)   // 뒤로가기로 이 교체를 되돌린다
        .commit();
왜 탭 전환은 addToBackStack 없이 바꾸므로 뒤로가기가 앱을 닫는다. 상세만 스택에 넣으면 뒤로가기 한 번에 원래 탭(새로 만든 홈·기기 화면)으로 돌아간다. 같은 화면이 두 겹 쌓이지 않게, 이미 상세가 떠 있으면 열지 않는다.

② 기기는 id로 다시 찾는다

viewModel.getDeviceList().observe(getViewLifecycleOwner(), devices -> {
    Device device = find(devices, deviceId);
    if (device == null) { close(); return; }
    statusCard.bind(HomeTile.of(device));
    infoCard.bind(DeviceInfo.of(device));
});
왜 Fragment 인자에는 Device 객체가 아니라 id 문자열만 넣는다. 객체를 넘기면 그 순간의 사본이라 켜기·끄기 결과가 반영되지 않는다. 목록을 관찰하면 홈 타일과 같은 값이 같은 때 바뀌고, 기기가 삭제되면 목록에서 빠지므로 상세도 저절로 닫힌다.

③ 같은 표시 규칙 다시 쓰기

// StatusCard.bind
StateChip.apply(chip, tile.chipText, tile.tone);
toggle.setChecked(tile.switchChecked);
toggle.setEnabled(tile.switchEnabled);   // 켜는 중이면 잠김
왜 상태 칩 글자·색, "켜는 중…" 잠금, 알 수 없음일 때 새로고침 버튼은 07b에서 HomeTile이 이미 정했다. 상세가 따로 규칙을 만들면 홈과 상세가 다른 말을 할 수 있다.

4용어 풀이

  • 뒤로 스택(back stack): FragmentManager가 기억하는 "되돌릴 화면 교체" 목록. popBackStack이 맨 위 하나를 되돌린다.
  • <include>: 다른 레이아웃 파일을 그 자리에 끼워 넣는 태그. android:id를 주면 끼운 뿌리 뷰의 id가 그것으로 바뀐다.
  • viewLifecycleOwner: Fragment의 화면(View) 수명. 뒤로 스택에 들어가 화면이 사라지면 관찰도 멈춘다.

5이해도 질문

  1. 상세에서 "켜기"를 누르고 실패하면 Snackbar는 어디에 뜰까? 하단 탭이 숨겨져 있는데.
  2. 상세가 열린 채 토큰이 틀려(401) 설정 탭으로 가면 상세는 어떻게 될까?
정답 보기
  1. 화면 맨 아래. MainActivity가 하단 탭이 보일 때만 그 위에 띄우고(setAnchorView), 숨겨져 있으면 기준 뷰 없이 띄운다.
  2. 탭 선택 리스너가 먼저 popBackStackImmediate(…, INCLUSIVE)로 상세를 닫은 뒤 설정 화면으로 바꾼다.
