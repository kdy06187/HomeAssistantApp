예시 2 · 코드를 다시 읽어 주는 주석은 지운다 DeviceViewModel

BEFORE
// 1. 전달받은 구체적인 데이터 변경 작업 실행
updateAction.accept(currentList.get(i));
// 2. 리스트 갱신 알림 (공통)
deviceList.setValue(currentList);
AFTER
updateAction.accept(currentList.get(i));
// 같은 리스트를 다시 넣어 옵저버를 깨운다.
deviceList.setValue(currentList);

"같은 리스트를 왜 다시 넣지?"는 코드만 봐서는 알기 어렵다. 그래서 그 한 줄에만 주석을 남겼다.

4이해도 질문

  1. isManualRefresh = false; // 즉시 잠금을 // 상태 갱신이 목록을 다시 내보내도 반복 요청하지 않게로 바꾼 이유는?
    정답 보기"즉시 잠금"은 코드가 하는 일(false 대입)을 다시 말할 뿐이다. 바꾼 주석은 이 줄이 없으면 생기는 문제(syncDeviceState → 목록 갱신 → 다시 sync 반복)를 알려 준다.
  2. 주석에 "불일치 #5"라고 쓰면 생기는 문제는?
    정답 보기문서를 열어야만 뜻을 알 수 있고, 문서 번호가 바뀌거나 문서가 사라지면 주석이 틀린 정보가 된다. 코드 리뷰어나 나중의 나에게 도움이 되지 않는다.
