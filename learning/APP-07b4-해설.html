APP-07b-4 해설 — 기기 탭: 상태 칩·삭제 버튼·순서 핸들

ui-1 브랜치 · UI 1차 07b · UI-20·UI-22, D3(순서는 기기 탭 핸들) · 2026-11-24

1한눈에 보기

  • 전: 기기 탭 한 줄 = 이름 + MATTER 같은 원시 값 + 화살표. 삭제는 길게 누르기로만 할 수 있어 찾기 어려웠고(UI-20), 추가 버튼은 "+" 아이콘뿐이었다(UI-22). 순서 바꾸기는 홈 섹션을 길게 눌러 끌었다.
  • 후: 한 줄 = 순서 핸들(48dp) · 이름 · "Matter / 직접 연결 (TCP_DIY)" · 상태 칩 · 삭제 버튼(빨간 휴지통, 48dp). 이름 부분을 누르면 상세, 아래쪽 "기기 추가" 글자 버튼.
  • 순서: 핸들을 누른 채 끌면 바뀌고, 손을 떼면 device_order에 저장한다. 홈 타일도 같은 순서를 따른다. TalkBack 사용자는 항목의 동작 메뉴에서 "위로 이동 / 아래로 이동"을 쓴다.
  • 삭제 확인: "‘이름’ 기기를 삭제할까요?" 대화상자의 삭제 버튼을 오류 색으로 구분. 길게 누르기 삭제는 없앴다(버튼으로 대신).

2흐름 그림 — 순서 바꾸기

3코드 해설

① 길게 누르지 않고 핸들로 끌기

@Override public boolean isLongPressDragEnabled() { return false; } // 핸들로만

holder.handle.setOnTouchListener((v, event) -> {
    if (event.getActionMasked() == MotionEvent.ACTION_DOWN) listener.onStartDrag(holder);
    return false;
});
왜 길게 누르기는 눈에 보이지 않는 기능이라 찾기 어렵고, 줄을 누르면 상세가 열리는 동작과 겹친다. 핸들은 "여기를 잡으면 움직인다"를 그림으로 보여 준다(D3).

② 드래그 중 갱신 미루기

if (dragging) {
    deferredDevices = devices;      // 지금 그리면 끌던 줄이 사라진다
} else {
    showDevices(devices);
}
… clearView: dragging = false; saveOrder(); showDevices(deferredDevices);
왜 기기 탭에 들어오면 기기마다 E5 상태 조회가 돌아 목록이 여러 번 다시 나온다. 그 사이에 notifyDataSetChanged가 오면 RecyclerView가 끌던 항목을 놓친다. 예전 위젯 편집의 "편집 중 갱신 무시"와 같은 생각이다.

③ 보조 기술용 이동 동작

ViewCompat.addAccessibilityAction(holder.itemView, "위로 이동",
        (v, args) -> { listener.onMoveBy(holder, -1); return true; });
왜 화면 읽기(TalkBack)에서는 손가락으로 끌기가 어렵다. 같은 결과를 내는 동작을 메뉴로 하나 더 준다. 다시 그릴 때 이전 동작 ID를 지우지 않으면 메뉴가 계속 늘어나므로 moveActionIds에 모아 두었다가 지운다.

4용어 풀이

  • ItemTouchHelper: RecyclerView 항목 끌기·밀기를 처리하는 도우미. onMove에서 자리를 바꾸고 clearView에서 끝을 안다.
  • 접근성 동작(AccessibilityAction): TalkBack의 "동작" 메뉴에 이름 붙은 기능을 추가하는 방법.

5이해도 질문

  1. 등록 중 임시 항목 위로 다른 기기를 끌어 올릴 수 있을까?
  2. 순서를 바꾼 뒤 홈 탭에 가면 바로 바뀐 순서가 보이는 이유는?
정답 보기
  1. 없다. move가 대상 자리가 임시 항목이면 거절하고, 임시 항목에는 핸들·삭제가 보이지 않는다.
  2. 홈은 탭에 들어올 때 새로 만들어지고, 목록을 그릴 때마다 같은 device_order로 정렬하기 때문이다.

6응용 실습

실습. 기기 개수 안내

  • 고칠 파일: fragment_device.xml(TextView 추가), DeviceFragment.java
  • 완료 기준: 등록 중에도 숫자가 늘지 않고, 삭제 뒤 줄어든다.
