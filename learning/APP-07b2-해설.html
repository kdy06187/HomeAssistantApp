APP-07b-2 해설 — 홈을 2열 타일 격자로

ui-1 브랜치 · UI 1차 07b · 목업 01 C안 · D2(위젯 구조 없앰) · 2026-11-24

1한눈에 보기

  • 전: 홈은 기기마다 큰 카드(섹션)를 그리고, 그 안에 또 하나의 목록(위젯: 전원·전력·차트)을 넣은 중첩 RecyclerView였다. 위젯 편집·드래그·삭제가 있었지만 삭제는 저장되지 않았다.
  • 후: 기기마다 타일 하나를 2열로 그린다. 타일 = 아이콘 · 스위치 · 이름 · 상태 칩 · (Matter) 전력 큰 숫자 + 누적 kWh. 이름 부분을 누르면 상세(07c 전까지는 지금의 상세 Activity), 오른쪽 아래 "기기 추가" 버튼.
  • 값과 그리기를 나눔: 타일에 보일 값은 HomeTile.of(device)(순수 Java)가 정하고, HomeTileAdapter는 그대로 화면에 옮긴다. 순서는 DeviceOrder가 홈·기기 탭 공통으로 정한다.
  • 연결만 끊음: 섹션·위젯 클래스와 레이아웃은 아직 지우지 않았다(승인 전). 홈이 더 이상 부르지 않을 뿐이다.

3코드 해설

① 타일 값은 순수 함수로

chipText = kind.text;
switchChecked = kind == DeviceStateLabel.Kind.ON;
switchEnabled = kind.canToggle;
showsPower = matter;
powerText = matter && kind == Kind.ON ? watts(device.getActivePowerW()) : NO_VALUE;
if (kind == Kind.OFFLINE) metaText = "기기 응답 없음";
else if (matter) metaText = "누적 " + kwh(device.getTotalEnergyKwh());
왜 "꺼진 기기에 지난 전력값 12 W를 보여 주면 안 된다", "오프라인은 스위치 잠금 + 이유"처럼 규칙이 많다. 어댑터 안에 두면 에뮬레이터로만 확인할 수 있지만, HomeTile로 떼면 HomeTileTest가 규칙마다 검사한다.
값 없음 숫자가 아직 없으면 "–"를 보인다(목업). 0 W와 "모름"을 구분하기 위해서다.

② 스위치를 다시 그릴 때의 함정

holder.toggle.setOnCheckedChangeListener(null);   // 먼저 뗀다
holder.toggle.setChecked(tile.switchChecked);
holder.toggle.setOnCheckedChangeListener((button, isChecked) -> {
    if (button.isPressed()) listener.onToggle(device, isChecked);
});
왜 RecyclerView는 화면 밖으로 나간 타일을 다른 기기에 다시 쓴다. 이전 기기의 리스너가 붙은 채로 setChecked를 하면 엉뚱한 기기에 E2가 갈 수 있다. 떼고 → 값 넣고 → 새로 붙인다. isPressed()는 사람이 누른 경우만 통과시킨다.

③ 전력 숫자는 문자열이 아니라 숫자로

BEFORE
String powerText = String.format(
  "실시간: %.1f W / 누적: %.4f kWh", w, kwh);
device.setPowerInfo(powerText);
AFTER (함께 저장)
device.setPowerInfo(powerText);
device.setEnergy(currentPowerW, totalEnergyKwh);
왜 타일은 전력을 큰 숫자로, 누적은 작은 줄로 따로 보여야 한다. 이미 합쳐진 문장은 다시 나누기 어렵다. 필드는 transient라 서버 JSON과 섞이지 않는다. powerInfo는 옛 위젯만 쓰므로 위젯을 지울 때 함께 정리한다.

4용어 풀이

  • GridLayoutManager(2): RecyclerView 항목을 2열 격자로 놓는 배치 관리자.
  • ExtendedFloatingActionButton: 아이콘 + 글자가 함께 있는 떠 있는 버튼. 아이콘만 있는 FAB보다 뜻이 분명하다(UI-22).
  • transient: Gson이 JSON으로 읽고 쓸 때 건너뛰는 필드 표시.

정답 보기
  1. 전력은 "–"(꺼졌으니 지금 값이 아님), 누적은 마지막으로 받은 값을 보인다.
  2. 저장된 순서에는 아직 id가 없고, 사용자가 방금 추가한 것이라 가장 먼저 눈에 띄어야 한다. 저장할 때도 빼서(serialize) 가짜 id가 남지 않게 한다.
  3. D3에 따라 순서 바꾸기는 기기 탭 핸들로 옮겼고 07b-4에서 붙인다. 그 사이에도 예전에 저장한 순서는 그대로 따른다.
