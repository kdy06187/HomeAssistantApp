APP-07g-2 해설 — 홈 타일에 설정 반영(줄 숨김·2칸)

ui-1 브랜치 · UI 1차 07g · D10·D11 · 2026-11-24

1한눈에 보기

  • 홈이 목록을 그릴 때 기기마다 TilePrefs에서 설정을 읽어 타일에 넘긴다.
  • W 끔 → 큰 전력 숫자 줄이 사라진다. 누적 끔 → "누적 … kWh" 줄이 사라진다. 단 오프라인이면 "기기 응답 없음"은 설정과 상관없이 보인다(상태 안내라서).
  • 2칸 → 그 타일이 한 줄을 다 쓴다. 1칸 타일 다음에 2칸이 오면 오른쪽이 빈칸으로 남는다(순서대로 채움, 자동 메우기 안 함).
  • 설정이 없는 기기·등록 중 타일은 기본값(지금 모양, 1칸)이다. 추이선 값 그리기는 07g-3.

2흐름 그림 — 설정에서 칸 수까지

3코드 해설

① 칸 수는 GridLayoutManager에게 물어보게 한다

grid.setSpanSizeLookup(new GridLayoutManager.SpanSizeLookup() {
    public int getSpanSize(int position) { return adapter.spanAt(position); }
});
왜 격자는 2열이고, 항목마다 "몇 열을 쓸지"를 이 콜백으로 묻는다. 값은 다른 표시 값처럼 HomeTile이 정하므로 테스트로 확인할 수 있다(등록 중 타일은 늘 1칸, TCP_DIY도 2칸 가능).

② 설정은 그릴 때마다 읽는다

List<Device> ordered = sorted(devices);
adapter.setDevices(ordered, configsFor(ordered));
왜 꾸미기 화면은 상세나 기기 탭에서 열리고, 홈으로 돌아오면 홈 화면이 새로 만들어진다. 그때 읽으면 따로 "설정 바뀜" 알림이 없어도 바로 반영된다. SharedPreferences는 메모리에 올라와 있어 기기 수만큼 읽어도 가볍다.

③ 상태 안내는 끄지 않는다

if (kind == OFFLINE)                metaText = "기기 응답 없음";
else if (matter && shown.total)     metaText = "누적 " + kwh(...);
왜 누적을 끈 사람도 기기가 응답하지 않는다는 사실은 알아야 한다. 꾸미기는 "값"을 고르는 것이고 "상태"는 칩·안내로 항상 보인다(D10).

4용어 풀이

  • span(칸): 격자에서 항목 하나가 차지하는 열 수. 2열 격자에서 span 2 = 한 줄 전체.
  • SpanSizeLookup: GridLayoutManager가 항목별 span을 묻는 콜백.

5이해도 질문

  1. 순서가 [A(1칸), B(2칸), C(1칸)]이면 화면은 어떻게 놓일까?
  2. 상세 화면의 전력 카드는 W를 끈 기기에서도 W를 보일까?
정답 보기
  1. 첫 줄 A + 빈칸, 둘째 줄 B, 셋째 줄 C + 빈칸. B가 첫 줄 남은 1칸에 들어갈 수 없어 다음 줄로 간다.
  2. 보인다. 상세는 HomeTile.of(device)(기본 설정)를 쓴다. 꾸미기는 홈 타일에만 적용된다.

6응용 실습

실습. 2칸 타일이면 W를 옆에 크게

  • 목표: 2칸 타일은 넓으니 W 숫자를 32sp로 키운다(1칸은 24sp 그대로).
  • 고칠 파일: HomeTileAdapter.onBindViewHolder 한 곳
  • 완료 기준: 375dp에서 2칸 타일의 W가 커지고, 1칸으로 바꾸면 돌아온다(RecyclerView가 뷰를 재사용하므로 두 경우 모두 값을 넣어야 함).
힌트holder.power.setTextSize(TypedValue.COMPLEX_UNIT_SP, tile.span == 2 ? 32 : 24). 재사용 때문에 else 쪽도 꼭 넣는다.
