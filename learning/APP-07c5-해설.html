APP-07c-5 해설 — 상세에서 기기 삭제

ui-1 브랜치 · UI 1차 07c · UI-34(파괴적 동작 구분) · 2026-11-24

1한눈에 보기

  • 상세 맨 아래에 빨간 글자 버튼 "기기 삭제"(휴지통 아이콘, 48dp). 누르면 기기 탭과 같은 확인 대화상자가 뜬다.
  • 삭제가 성공하면 상세가 저절로 닫힌다. 닫는 코드를 따로 쓰지 않았다. 목록이 새로 오면 그 기기가 없으므로 07c-1의 "기기가 없으면 닫기"가 일한다.
  • 이미 지워진 기기(404)여도 같은 길로 닫힌다. 기기 쪽 해제 실패 경고(unpaired:false)는 06c 그대로 MainActivity가 대화상자로 띄운다.
  • 확인 대화상자는 DeleteDeviceDialog 한 곳으로 옮겨 두 화면이 같은 문구·색을 쓴다.

2흐름 그림 — 삭제 뒤 닫히기

3코드 해설

① 닫기를 결과에서 추론한다

device = find(devices, deviceId);
if (device == null) { close(); return; }
왜 "삭제 성공하면 닫기"를 따로 만들면 "이미 삭제됨(404)" "다른 폰에서 삭제" 같은 경우마다 또 만들어야 한다. 화면이 목록이라는 사실을 보고 "내 기기가 없으면 닫는다" 한 가지만 지키면 모든 경우가 같은 길로 간다.

② 같은 대화상자를 한 곳에

DeleteDeviceDialog.show(this, viewModel, device);   // 상세
DeleteDeviceDialog.show(DeviceFragment.this, viewModel, device);   // 기기 탭
왜 문구나 버튼 색을 바꿀 때 한 곳만 고치면 된다. 07b에서 AddDeviceDialog를 뺀 것과 같은 방법이다.

4용어 풀이

  • 파괴적 동작: 되돌리기 어려운 동작(삭제 등). 다른 버튼과 떨어뜨리고 오류 색으로 구분하고, 한 번 더 묻는다.
  • TextButton.Icon: 배경 없는 글자 버튼에 아이콘이 붙은 Material 3 스타일.

5이해도 질문

  1. 삭제를 누르고 서버가 꺼져 있으면(통신 실패) 상세는 닫힐까?
  2. 삭제 확인 대화상자를 띄운 채 화면을 돌리면?
정답 보기
  1. 닫히지 않는다. 목록을 다시 받지 못했으므로 기기가 그대로 있고, "통신 실패" 토스트만 뜬다.
  2. AlertDialog는 회전 때 사라진다(DialogFragment가 아니므로). 다시 누르면 된다. 07b 기기 탭과 같은 동작이다.

6응용 실습

실습. 이름을 다시 입력해야 삭제

  • 목표: 대화상자에 입력칸을 두고, 기기 이름과 같게 입력해야 "삭제" 버튼이 켜지게 한다.
  • 고칠 파일: fragment/DeleteDeviceDialog.java 한 곳(두 화면에 함께 적용됨)
  • 완료 기준: 빈칸·다른 이름이면 삭제 버튼이 꺼져 있고, 같은 이름이면 켜진다.
힌트setView(EditText) 뒤 show()하고, getButton(BUTTON_POSITIVE).setEnabled(false)로 시작해 TextWatcher에서 켜고 끈다.
